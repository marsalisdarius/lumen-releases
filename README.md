# Lumen Photo: downloads

Lumen is a photo library and editor for Windows with on-device AI (masks, remove, sky replacement,
denoise and super resolution). This repository only hosts the releases.

## Download

Open **[the latest release](../../releases/latest)** and download:

- `Lumen-Setup-<version>.exe`: installer. Installed copies **update themselves** from this page: a new
  version downloads in the background and installs when you restart Lumen (Settings shows the status).
- `Lumen-<version>-portable.exe`: runs without installing. It can't update itself; it tells you when a new
  version is available.

The app is unsigned, so Windows SmartScreen may say it protected your PC: click **More info → Run anyway**.

Your photos, edits and AI processing stay on your computer; nothing is uploaded.
